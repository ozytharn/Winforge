# WinForge External Testing

## Scope

This package is intended for controlled external testing of the internal release candidate.

## Tester guidance

- install the package locally
- verify the app starts
- run a scan and confirm results are reported with evidence and limitations
- export diagnostics if an issue occurs
- preserve local data before any reinstall or upgrade

## Feedback collection

Feedback should be captured through a structured issue or bug template. The app does not upload or transmit local diagnostics automatically.
